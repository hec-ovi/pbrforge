# Street albedo sources

Continuous color sources generated with OpenAI image generation, each representing 1 x 1 m. Opaque sRGB originals are 1254 x 1254 px. Import recipes use whole-image 1024 px downsampling and the public seam gate. Images contain no structural joints or markings; PBR response and family tone are authored in [street image recipes](../../batch/cyberpunk/street-image-finishes.json).

- [Asphalt](asphalt-v2.png): fine charcoal aggregate.
- [Precast](precast-v1.png): smooth neutral cement.
- [Graphite](graphite-v1.png): continuous dense dark mineral finish.
- [Orange](orange-v3.png): fine dark copper-orange coating.

These sources support candidate finishes. Fitted-city visual acceptance is separate from import validation.
