# Exterior concrete sources

[Accepted native finishes](accepted.json) records fourteen complete Exterior source sets, their canonical keys, exact counterparts and map hashes. The main catalog preserves their source metadata and image bytes. Exact counterparts add `-exact` to the kind, use aspect `[1,1]` and share the original maps. Every set uses variant `native`.

Built-in Imagegen photographs feed pbrforge `from-image`. Original sources remain beside this index. The shared catalog keeps its 4 x 4 m field scale. Exterior owns 7 x 3.5 m panel divisions and their actual joints.

- [Cast](cast.png), [prompt](prompts/cast.md): fine neutral cement and distributed pores.
- [Weathered](weathered.png), [prompt](prompts/weathered.md): worn paste with dark mineral fines.
- [Graphite](graphite.png), [prompt](prompts/graphite.md): charcoal pigmented concrete.

[Recipes](../../batch/cyberpunk/exterior-native/) publish 1024-pixel albedo, restrained relief, roughness, AO and packed metallic-roughness. Exterior style bindings select the named native variants at every tier.
